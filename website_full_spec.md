## 2. 🎨 Design System & Color Tokens

Built on modern luxury editorial principles, dark-mode surfaces, glassmorphism, and responsive grid layouts.

| Token Name | Hex / Value | Usage & Visual Purpose |
|---|---|---|
| **Base Dark Background** | `#121214` | Matte charcoal background for deep contrast |
| **Surface / Card Container** | `#1C1F2B` | Elevated glassmorphic card container background |
| **Container Border Stroke** | `#2A2E3D` (1px) | Subtle micro-border separation |
| **Primary Accent Gold** | `#C5A880` / `#D4AF37` | Scissors emblem, CTA buttons, 4.9★ stars, price tags |
| **Secondary Accent Linen** | `#F4F1EA` | Soft warm text & highlight pills |
| **Headline Text** | `#FFFFFF` | High-contrast pure white titles |
| **Body Text** | `#CBD5E1` | Soft slate gray for optimal readability |

### 🖋️ Typography Pairings
- **Display / Section Titles:** `Playfair Display` (Serif, 700 Bold / Italic)
- **Body, Inputs & UI Buttons:** `Plus Jakarta Sans` or `Inter` (Sans-Serif, 400 Regular / 600 Semi-Bold / 800 Bold)
